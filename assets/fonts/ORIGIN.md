# Display fonts

Unmodified DejaVu Sans regular and bold, copied from the existing VPS's Debian `fonts-dejavu-core` package. Upstream: https://dejavu-fonts.github.io/ . Copyright and redistribution terms are preserved in `LICENSE.txt`.

These fonts render Latin and Vietnamese family records on the VPS. The tablet receives only packed four-color pixels; it does not need a font or Unicode layout engine.
